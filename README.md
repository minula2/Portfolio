## 🚀 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/minula2/Portfolio.git
cd Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 4. Build for production
```bash
npm run build
```

## 🌐 Deploying to Vercel (1-Minute Setup)

1. Go to [vercel.com](https://vercel.com) and sign in with your GitHub account (`minula2`).
2. Click **"Add New Project"**.
3. Select the **`Portfolio`** repository from your GitHub repo list and click **Import**.
4. Vercel will automatically detect **Vite** as the framework:
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **Deploy**. Within 30 seconds, your site will be live at `https://portfolio-*.vercel.app`!
